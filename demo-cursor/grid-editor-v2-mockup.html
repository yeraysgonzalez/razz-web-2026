Broadcast. Parent Design has three channels: text color, cell layout, and cell chrome. Cell Design always shows the layout and chrome dashboard — those fields update when the Grid broadcasts. There is no Listen / Custom control on the cell. Editing a cell field styles that cell only; Use Grid styles puts it back on the broadcast. Child text, media, and buttons are listed in the cell. Text color comes from the Grid; size and heading stay on the text block.
Caps. Minimum 4 cells — Remove is disabled with a reason, not a silent fail. Maximum 6 blocks per cell — Add is disabled at 6. Add list is Text, Buttons, Media. Nested Containers on five live sites stay (grandfather).
Click order. Parent chrome selects the grid. A cell on canvas (or a list row) selects that cell. Breadcrumb: Grid > Cell N.
